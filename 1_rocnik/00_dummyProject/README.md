# 00 – Dummy projekt

Tohle není zadání – je to jen ukázka, jak vypadá projekt uložený v repozitáři.

Vyzkoušej si:
1. Otevřít tento projekt ve Visual Studiu a spustit ho (F5).
2. Trochu si pohrát s kódem v `Program.cs`.
3. Uložit změnu (commit) a nahrát ji na GitHub (push) – viz [docs/jak-zacit.md](../../docs/jak-zacit.md).

Každý další projekt bude mít vlastní složku ve stejném ročníku, např. `01_helloworld`, `02_kalkulacka`.
