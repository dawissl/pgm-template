# Jak začít

## 1. Vytvoř si vlastní repozitář z tohoto template

1. Klikni na tlačítko **"Use this template"** → **"Create a new repository"** (nahoře na stránce repa).
2. Pojmenuj repozitář (např. `portfolio-programovani`).
3. Nastav jako **Public** (nebo Private, pokud nechceš, aby to viděli ostatní).
4. Klikni **"Create repository"**.

## 2. Naklonuj si repozitář na počítač

**Varianta A – GitHub Desktop (doporučeno, žádná příkazová řádka):**
1. Nainstaluj [GitHub Desktop](https://desktop.github.com/).
2. Na stránce svého nového repa klikni **Code → Open with GitHub Desktop**.
3. Vyber si složku na disku a klikni **Clone**.

**Varianta B – příkazová řádka:**
```bash
git clone https://github.com/TVOJE-JMENO/NAZEV-REPA.git
```

## 3. Otevři ve Visual Studiu

- Otevři složku `1_rocnik/00_dummyProject` jako projekt.
- Vyzkoušej, že jde projekt spustit (F5).

## 4. První commit

1. Uprav nějaký soubor (klidně jen zkus, jestli commit funguje).
2. V GitHub Desktop: napiš zprávu commitu → **Commit to main** → **Push origin**.
3. Zkontroluj na GitHubu, že se změna objevila.

## 5. Nový projekt = nová složka

Když dostaneš nové zadání, vytvoř si novou složku ve svém ročníku ve formátu `číslo_nazevProjektu`, např. `01_helloworld`. Do ní ulož svůj projekt.
